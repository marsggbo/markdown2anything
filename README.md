# Markdown2Anything

**写一次，发到所有平台。**

微信公众号 · 知乎 · 小红书 · Twitter · PPT · Word——排版、截图、AI 文案、自动发布，全在 VS Code 侧边栏里一条龙搞定。

---

## 你还在重复这些吗？

写完一篇技术文章，真正的工作才刚开始——

- 微信公众号：粘贴进去，代码块炸了，图片重传，公式消失
- 知乎：同上，再来一遍
- 小红书：截图、裁图、配文案、标签一个个打，传图
- Twitter：重写成英文串推，280 字一条，不知道怎么拆
- PPT：「能不能帮我把这篇文章做成 PPT？」——然后自己做到凌晨

**Markdown2Anything 把这些全变成几次点击。**

---

## 上手只需 3 步

**1. 安装插件**

VS Code 插件市场搜索 `Markdown2Anything`，或：

```
ext install marsggbo.markdown2anything
```

**2. 打开预览**

打开任意 `.md` 文件 → `Cmd+Shift+W`（Mac）/ `Ctrl+Shift+W`（Windows）

**3. 选平台，点按钮**

右侧面板直接操作。AI 文案功能需先配置一次 LLM：工具栏 `⚙️ LLM` → 选预设（DeepSeek / 硅基流动等）→ 填 API Key → 保存。

## 发布到各平台

### 📱 小红书——最省事的长图发布流程

1. 工具栏点 `📱 小红书`
2. 选导出模式：**默认 HTML 截图**（保留你的主题风格）或 **手机自适应截图**（1080×1440，适合手机阅读）
3. 点「📸 生成预览」，满意后点「💾 一键导出」
4. AI 自动写好标题 + 正文 + 标签，你来改改
5. 点「🚀 发布小红书」——浏览器自动打开，图传好、字填好，你只需最后点「发布」

两种模式都有完整的尺寸、字号、内边距控制，参数可以「★ 设为默认」记住，随时「↺ 出厂值」还原。

### 🟢 微信公众号

一键复制带内联样式的 HTML——粘贴到公众号编辑器，排版、代码高亮、LaTeX 公式全部保留，一个字不用改。支持 API 直接上传草稿箱。

### 🔵 知乎

自动打开知乎编辑器，标题 + 正文 + 代码 + 公式一次性填好，不用一格格复制粘贴。

### 🐦 Twitter (X)

AI 把长文拆成串推 thread，每条控制在 280 字内，配图自动按顺序挂到各条推文上。

## AI 功能

所有 AI 功能共用一套 LLM 配置，接任意 **OpenAI 兼容接口**：

| 预设 | 接口 |
|------|------|
| 硅基流动 | `api.siliconflow.cn/v1` |
| DeepSeek | `api.deepseek.com/v1` |
| OpenRouter | `openrouter.ai/api/v1` |
| Groq | `api.groq.com/openai/v1` |
| 本地 Ollama | `localhost:11434/v1`（无需 Key）|
| OpenAI | `api.openai.com/v1` |

选预设自动填好接口地址和模型名，支持同时保存多套配置，可**重命名、一键切换**（同一平台不同 Key 各起一名互不覆盖，Key 加密存本地）。

**AI 能做什么：**
- 小红书文案：标题 + 正文 + 标签，生成后可手动改
- Twitter 串推：按字数自动拆分，控制语气和风格
- PPT 改写：把文章重写成演讲结构，代码 / 图片 / 公式原样保留
- 每次生成自动存档，`◀ ▶` 切换版本对比，随时回滚

## 导出格式

| 格式 | 引擎 | 特点 |
|------|------|------|
| PPT（Slidev） | Playwright | 视觉最佳，代码高亮 / 公式 / 图片完整 |
| PPT（Marp） | npx（无需安装） | 轻量，3 套主题，秒出 |
| PPT / Word（Pandoc） | pandoc（自动下载） | 真正可编辑的 PPTX / DOCX，公式用 OMML |
| HTML | 内置 | 带内联样式，保存到 md 同目录 |

依赖首次使用时自动下载到 VS Code globalStorage，不污染项目目录。

## 14 套主题 · 实时预览

内置主题涵盖：微信经典 / Claude Pro / Medium 编辑 / 简约蓝 / 科技博客 / 知乎 / 极简黑白 / 春日清新 / 学术论文 / 小红书 / Notion / 深夜极客 / macOS 简约 / 暖色知识

## 安全

- API Key 存入系统钥匙串（VS Code SecretStorage），不写入任何文件
- Cookie 只存本地，不经过第三方服务
- 自动发布走 Playwright 真实浏览器 + Cookie 注入，模拟真实操作
- **默认不替你点最后「发布」**——内容填好后停下，你核对、改改再发

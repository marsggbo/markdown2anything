🎨 自定义样式

在此输入 CSS，覆盖当前主题的样式。
所有规则需以 .article-wrapper 开头才能生效。

📐 可用选择器
.article-wrapper — 文章容器（背景/内边距）
.article-wrapper h1/h2/h3/h4 — 各级标题
.article-wrapper p — 正文段落
.article-wrapper strong — 加粗文字
.article-wrapper a — 链接
.article-wrapper blockquote — 引用块
.article-wrapper pre.mac-code — 代码块容器
.article-wrapper code:not([class]) — 行内代码
.article-wrapper table — 表格
.article-wrapper table th — 表头
.article-wrapper table td — 表格单元格
.article-wrapper .table-wrapper — 宽表格滚动容器（溢出时内部横向滚动）
.article-wrapper ul / ol — 列表
.article-wrapper img — 图片
.article-wrapper figure — 图片容器
.article-wrapper figcaption — 图片说明
.article-wrapper hr — 分割线
.math-block / .math-inline — KaTeX 公式
⚡ 常用属性
color — 文字颜色，如 #333 / rgb(50,50,50)
font-size — 字号，如 16px / 1.1em
font-family — 字体，如 'PingFang SC', serif
line-height — 行高，如 1.8em
background — 背景色/渐变
border-left — 左边框，如 4px solid #07c160
border-radius — 圆角，如 8px
padding / margin — 内/外边距
text-align — 对齐：left/center/right
letter-spacing — 字间距，如 0.05em
